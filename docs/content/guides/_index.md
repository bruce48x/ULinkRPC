这里放面向真实项目接入和上线前判断的专题指南。

计划中的专题：

- 错误处理：`RpcStatus`、异常传播、客户端失败模式。
- 安全模型：`TransportSecurityConfig`、TLS / WSS 关系、威胁边界。
- DTO 版本演进：JSON、MemoryPack、字段增删和灰度发布。
- 连接生命周期：连接、断线、keepalive、停止、重连归属。
- 线程模型：客户端 callback 执行线程、Unity 主线程要求、同步策略。
- 性能调优：transport / serializer 选择、payload 大小、benchmark 状态。
- Godot 接入：与 Unity 对等的 starter 和运行路径。
