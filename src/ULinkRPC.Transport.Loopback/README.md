# ULinkRPC.Transport.Loopback

In-memory loopback transport for local tests in ULinkRPC.

## Install

```bash
dotnet add package ULinkRPC.Transport.Loopback
```

## Documentation

API reference: https://bruce48x.github.io/ULinkRPC/reference/api/

Design boundary: https://bruce48x.github.io/ULinkRPC/concepts/design-boundary/
